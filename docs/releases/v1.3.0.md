PowerStudio 1.3 sends networks the other way: a network drawn or edited in PowerStudio now goes out as a PSS/E RAW
file that PSS/E, PowerFactory, PowSyBl and other tools that read RAW can open. The calculations are unchanged from 1.2.

**Export to PSS/E RAW.** File, Export, "PSS/E RAW file" (or "RAW" in the command palette) writes the network as the
active study case composes it, as RAW version 33, which most tools read, or 35, for PSS/E 35 and later. The bus records
carry the voltages of a load flow with taps, shunt sections and reactive outputs where they are, so the other tool
starts from the solution rather than from flat voltages. Before you save, PowerStudio reads the file back with its own
RAW import, solves it again and compares every busbar: "Verified" when every one keeps its voltage, otherwise the
busbar that differs most and why. The dialog lists what RAW cannot hold exactly. RAW is a bus-branch format, so closed
switches join their busbars, external grids become generators that hold their voltage, and admittances a RAW record
has no place for become fixed shunts at the same bus; none of these changes the load flow. Imported RAW and MATPOWER
networks keep their bus numbers. The file does not carry dynamic models (DYR), short-circuit sequence data, the
diagram or the study case settings.

The writer is the one `ps export --raw` has used since 1.0: every reference model (the samples, MATPOWER cases up to
2,869 buses, the CGMES configurations and the PSS/E files) written in both versions reads back to the same voltages
to 1e-14 p.u., and PowSyBl's reading of the same files agrees with PowerStudio's load flow to 4.2e-11 p.u. or better.

Documents saved by 1.2, 1.1, 1.0 and 0.1 open unchanged and solve as they did.

**Files**

- `PowerStudio.html`: the app. Open it in a browser; it needs no installation or network.
- `PowerStudio.html.sha256`: its checksum. Check it with `shasum -a 256 -c PowerStudio.html.sha256`, and the build's
  provenance with `gh attestation verify PowerStudio.html --repo swiftugandan/powerstudio`.
- `PowerStudio.cdx.json`: the software bill of materials.

docs/guide/save-share-protect.md ("Open the network in another tool") shows how to export, and docs/ENGINE.md
("PSS/E RAW export") what the export computes and checks.
