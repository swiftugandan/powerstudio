PowerStudio 1.3.1 fixes a diagram that could not be seen on some GPUs. The calculations are unchanged from 1.3.

**Fixed: a solid red diagram.** On an iMac with an AMD Radeon R9 M395 (AMD GCN 3 on Metal), the diagram area was a solid
red rectangle, while the badge said WebGPU and no error appeared. Resolving the multisampled frame straight into the
canvas gave red, with no error from the browser. Frames now resolve into a texture of the renderer's own, which is
copied to the canvas, so the diagram draws correctly on that GPU and stays on WebGPU. This costs one more canvas-sized
texture on every GPU.

**A stronger check at start-up.** The GPU self-test now sends a known colour through the same path every frame takes,
from the grid shader to a canvas texture. A GPU that fails it falls back to Canvas 2D, and the badge gives the reason.
The old self-test only cleared a small texture, so it passed on this GPU and the fallback never ran.

Documents saved by 1.3, 1.2, 1.1, 1.0 and 0.1 open unchanged and solve as they did.

**Files**

- `PowerStudio.html`: the app. Open it in a browser; it needs no installation or network.
- `PowerStudio.html.sha256`: its checksum. Check it with `shasum -a 256 -c PowerStudio.html.sha256`, and the build's
  provenance with `gh attestation verify PowerStudio.html --repo swiftugandan/powerstudio`.
- `PowerStudio.cdx.json`: the software bill of materials.
