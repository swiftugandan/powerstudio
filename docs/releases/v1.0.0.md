PowerStudio 1.0 rebuilds the calculations as a Rust engine running in WebAssembly and brings them to the standard a
national transmission operator's studies need, each checked against an independent reference. It is still one HTML
file that runs offline in the browser and sends nothing anywhere.

**Engine.** All calculations run in a Rust engine, compiled to WebAssembly and run in a pool of workers. It solves the
25,000-bus ACTIVSg grid's load flow in about 0.3 s and opens the 70,000-bus one.

**Data exchange.** CGMES 2.4.15 and 3.0 (import, and the operating point back out as SSH and SV), PSS/E RAW 32, 33
and 35 with DYR dynamic data (import and export), MATPOWER cases. Imports agree with PowSyBl on 12 CGMES
configurations, 23 RAW files and 7 large MATPOWER grids.

**Load flow and contingency.** Tap changers, phase shifters and switched shunts that regulate, remote voltage control,
voltage-dependent loads, distributed slack, area interchange, HVDC links. Contingency analysis with your own
multi-element contingencies, remedial actions and screening, in parallel. Checked against PowSyBl and OpenLoadFlow.

**Short circuit.** IEC 60909-style: power station units, three-winding transformers corrected per winding pair,
asynchronous motors, network feeders, converter-fed sources, neutral earthing, breaking currents and fault impedance.
It meets the values of the IEC TR 60909-4 example network to 1e-4 kA, three-phase, line-to-line and line-to-earth.

**Stability.** An implicit DAE solver with round-rotor machines and the PSS/E library's exciters, governors and
stabilisers, edited in the app or read from DYR files. Agrees with ANDES on its published cases.

**Workspace.** Projects with study cases, scenarios and variants, a run log with result hashes, a spreadsheet data
manager, result comparison with earlier runs, a printable study report, and diagrams that stay fast at national
scale.

**Assurance.** Browser tests in Chromium (WebGPU and Canvas 2D), Firefox and WebKit, and an accessibility audit
(WCAG 2.1 A and AA). Trusted Types are enforced, and projects can be exported encrypted with a passphrase. The engine
builds reproducibly, and this release carries a CycloneDX bill of materials and GitHub attestations. An operator
benchmark kit (`ps compare`) compares PowerStudio with your own tool on your own model.

**Files**

- `PowerStudio.html`: the app. Open it in a browser; it needs no installation or network.
- `PowerStudio.html.sha256`: its checksum. Check it with `shasum -a 256 -c PowerStudio.html.sha256`, and the build's
  provenance with `gh attestation verify PowerStudio.html --repo swiftugandan/powerstudio`.
- `PowerStudio.cdx.json`: the software bill of materials.

Documents saved by 0.1 open unchanged. docs/USER-GUIDE.md shows how to use the app, docs/ENGINE.md what each
calculation computes, and docs/TEST-REPORT.md the results of every check. The short-circuit calculation follows IEC
60909-0 but is not certified against it.
